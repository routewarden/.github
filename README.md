- **Grafana Threat Intelligence Dashboard**: Canonical template located at [`dashboards/routewarden-overview.json`](dashboards/routewarden-overview.json) and documented at [https://routewarden.github.io/cli/dashboard](https://routewarden.github.io/cli/dashboard)
